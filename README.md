# 🏟️ Estadio Pokémon: De Java a la Web

¡Bienvenido al Estadio Pokémon! Este proyecto es una evolución visual de una aplicación de consola desarrollada originalmente en **Java**.

## 🚀 Sobre el Proyecto
Este repositorio demuestra la capacidad de transformar lógica pura de programación orientada a objetos (POO) en una interfaz web interactiva y moderna.

### 🛠️ Tecnologías utilizadas
* **Lógica Base:** Java (Clases, Herencia y Polimorfismo).
* **Frontend:** HTML5 & CSS3 (Diseño Glass-morphism).
* **Backend/Lógica Web:** JavaScript ES6.
* **Despliegue:** GitHub Pages.

## 🎮 Cómo Funciona
La aplicación utiliza la lógica de niveles definida en el código original:
1.  **Selección:** Elige un entrenador (Ash, Misty o Tom).
2.  **Combate:** El sistema compara los niveles de los Pokémon.
3.  **Resultado:** Se muestra el ganador o el mensaje de empate original de Java.

## 📂 Estructura del Código
* `logica.js`: Contiene la traducción de las clases `Pokemon`, `Entrenador` y `Combate`.
* `index.html`: Estructura del estadio y zonas de combate.
* `styles.css`: Estética retro con fuentes de Google Fonts.
